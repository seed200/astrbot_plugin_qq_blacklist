# QQ 黑名单 / 限流

支持两种针对 QQ 号的模式：

1. **永久屏蔽**：这个 QQ 的任何消息都不会触发机器人。
2. **间歇屏蔽**：每个自然小时最多放行 N 条消息，超过 N 条后拦截，到下一个整点自动恢复。

适用于 AstrBot `>= 4.24.0`，平台适配器为 `aiocqhttp`（OneBot v11）。

## 核心功能

- **永久屏蔽**：指定 QQ 号的任何消息都不会触发机器人。
- **间歇限流**：指定 QQ 号每个自然小时最多触发 N 条消息，防止刷屏。
- **防止多机器人互刷（左脚踩右脚）**：一个群里有多个机器人时，把其它机器人的 QQ 号加入永久屏蔽。这样它们不会互相触发，避免两个或多个机器人无限对话、停不下来。

> 防互刷需要手动把群里其它机器人的 QQ 号填进「永久屏蔽 QQ 号」，插件不会自动识别哪个号是机器人。

## 安装

把整个仓库目录放到 AstrBot 的插件目录：

```text
AstrBot/data/plugins/astrbot_plugin_qq_blacklist/
```

然后重启 AstrBot，或在 WebUI 的插件页面重载插件。

## 在哪里配置

AstrBot WebUI：

```text
插件 -> QQ 黑名单 / 限流 -> 插件配置
```

- `启用黑名单`：总开关
- `永久屏蔽 QQ 号`：每行一个 QQ 号
- `间歇屏蔽 QQ 号（每小时限流）`：每行一个 QQ 号
- `间歇屏蔽每小时可接收条数`：默认 `5`

示例：

```text
永久屏蔽：
123456789

间歇屏蔽：
987654321
```

配合 `每小时可接收条数 = 5`，`987654321` 每个自然小时最多能触发机器人 5 条消息。

### 多机器人防互刷示例

如果群里有机器人 A、B、C，只想让 A 正常说话，就把 B 和 C 的 QQ 号填进 A 的
「永久屏蔽 QQ 号」：

```text
B 的 QQ 号
C 的 QQ 号
```

这样 B、C 的消息不会触发 A，A 就不会和它们来回对话。

## 配置文件

```text
AstrBot\data\config\astrbot_plugin_qq_blacklist_config.json
```

```json
{
  "enabled": true,
  "permanent_blacklist": ["123456789"],
  "hourly_blacklist": ["987654321"],
  "hourly_limit": 5
}
```

## 行为说明

- 永久屏蔽优先于间歇屏蔽，同一个 QQ 同时在两个列表里时按永久处理。
- 间歇屏蔽按**自然小时**（例如 01:00–01:59）计数，到 02:00 自动清零。
- 只有被放行的消息才计数；被拦截的消息不增加计数。
- 计数会保存到插件数据目录的 `hourly_state.json`，重启 AstrBot 不会立刻清零。
- 被拦截的消息不会进入命令解析、群聊上下文、主动回复或 LLM 请求。
